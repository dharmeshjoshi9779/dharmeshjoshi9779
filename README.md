### 👨‍💻 About Me

Backend developer from **Rajkot, Gujarat, India**. I build scalable web platforms, multi-tenant SaaS products and third-party integrations, mostly with **Laravel**.

- 🏢 Full-time freelance Laravel developer since 2021. Before that I was a Senior PHP Developer at TJCG, leading teams and client projects.
- 🔐 Most of my work has been done under NDA for clients, so I'm unable to share the source code publicly.
- 🚀 I've built multi-tenant CRM/HRM/POS platforms, AI content platforms, booking systems and cargo management portals.
- 🖥️ I set up and manage **Hostinger VPS** servers from scratch for Laravel apps: Nginx, PHP, MySQL, SSL, queue workers and cron jobs.
- ⚙️ I automate deployments with **CI/CD pipelines using GitHub Actions**, so every push to production is tested and deployed consistently.
- 🤖 Currently working with **OpenAI and Gemini** APIs in Laravel apps.
- 🌱 Currently learning **AI / Machine Learning** and exploring new ways to bring it into real-world products.
- 💬 Ask me about payment gateways, real-time apps, Laravel performance or legacy PHP upgrades.
- ⚡ Fun fact: I've integrated 25+ third-party APIs, from Stripe to Redbus.
